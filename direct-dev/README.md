## Insurance — lokální vývoj

**BE endpoint pro lokální vývoj:**
```
http://localhost:8976/restapi-property/services/rest/property/insurance/v6/calculation
```

**Kde změnit API URL na FE straně:**
- Projekt: `DIF`
- Soubor: `src/services/insurance/const.ts`

> Tady upravíš URL když přepínáš mezi lokálním BE a jiným prostředím.
